# E-commerce Sales & Business Analytics

An end-to-end data analytics project focused on analyzing e-commerce sales data and generating business insights using Python, Pandas, SQL, SQLite, and Power BI.

---

## 📌 Project Overview

This project analyzes an e-commerce dataset containing **51,318 records** across orders, customers, products, categories, markets, regions, segments, sales, revenue, expenses, discounts, shipping, and other business attributes.

The project follows a practical data analytics workflow:

**Data Cleaning → Exploratory Analysis → SQL Analysis → Power BI Dashboard → Business Insights**

The main objective is to move beyond simply writing code or SQL queries and use data to answer meaningful business questions related to sales performance, products, customers, markets, and segments.

---

## 🎯 Objectives

- Clean and prepare raw e-commerce data for analysis
- Perform exploratory data analysis using Python and Pandas
- Create a SQLite database from the dataset
- Analyze business performance using SQL
- Answer business-oriented questions using SQL queries
- Identify patterns across products, categories, markets, regions, and segments
- Build an interactive Power BI dashboard
- Convert analytical results into meaningful business insights
- Document the complete analytics workflow for portfolio and internship purposes
